# Google Maps Reviews Tracker — v42.0.0 Beta 1

**Windows 10/11 x64 — ProTech / alghad.digital**

الإصدار الجديد يتضمن الواجهة المعتمدة RTL/LTR، Dashboard برسوم وبيانات حقيقية من السجلات المحفوظة، تنقل جانبي محسن، بطاقات تقييمات ومراجعات وتنبيهات، وتصميم Responsive.

## تشغيل Windows
التنزيل من [GitHub Releases](https://github.com/Abdealmalk007/GoogleMapsReviewsTracker/releases). شغّل ملف `GoogleMapsReviewsTracker_v42_Setup.exe`، ثم التطبيق من قائمة Start. المثبّت حاليًا **Beta غير موقّع رقميًا**؛ راجع SHA256SUMS.txt.

## ملاحظات البيانات والأمان
- تم اختبار المثبّت في مجلد QA مستقل؛ لا تحتوي حزمة التثبيت على قاعدة بيانات عميل، أو مفتاح API، أو ملفات أسرار.
- مؤشر تقييم الفروع يحسب من بيانات تقييمات الفروع المحفوظة. المراجعات الظاهرة في Places API عينة محدودة وليست جميع المراجعات.
- يتطلب جلب مراجعات المواقع الموثّقة المملوكة للمستخدم صلاحيات Google Business Profile OAuth وتكوينًا مصرحًا به؛ لم تُعتمد تجربة مراجعات حية شاملة.
- تحليل المشاعر بالذكاء الاصطناعي اختياري ويحتاج تثبيت اعتماديات إضافية من `requirements-ai.txt`.

## أدلة التطوير
- `dashboard_v42.py`: نموذج لوحة القيادة واحتساب المؤشرات الحقيقي.
- `ui_v42.css`: تصميم Responsive وتنسيق RTL.
- `test_dashboard_v42.py`: ستة اختبارات حساب وفلترة.
- `test_v41_offline.py`, `test_s2_v41.py`, `test_s2_sync.py`, `test_gbp_v41.py`: اختبارات تراجع للمزامنة والبيانات والواجهات الرسمية.
- `UI_V42_QA.json`: فحص الواجهة المعتمدة بالعربية والإنجليزية.
- `DESIGN_V42_APPROVED_AR.md`: وثيقة التصميم المعتمد.

## التحسينات على v41
- شاشة رئيسية أكثر اتساقًا بدل القوائم القديمة المزدحمة.
- استقرار الشريط الجانبي والهوامش والتجاوب على دقات متعددة.
- تصحيح تغليف `reportlab.lib` في إعدادات بناء v42 لإصلاح خطأ PDF السابق.
- إشارات صريحة لحدود البيانات وتغطيتها بدل إظهار أرقام تقديرية.

**حالة الإصدار:** Beta، ليست شهادة بأن التكامل الحي مع Google اكتمل.
