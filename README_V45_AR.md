# Google Maps Reviews Tracker v45.0.0 Beta 1

**ALGHAD DIGITAL · ProTech | Windows 10/11 x64**

## الواجهة والهوية المعتمدة

- أيقونة جديدة تعكس الخرائط وتقييمات الفروع والمراجعات والتحليلات. صيغتا PNG وICO، وتظهر في ملف Windows وداخل واجهة التطبيق.
- لوحة Dashboard بأربع بطاقات مؤشرات تعرض القيم الحقيقية الموجودة في البيانات المحفوظة، ولا تعتمد على أرقام تجريبية.
- أربع بطاقات ميزات قابلة للاستخدام: **تتبع المراجعات**، **إدارة الفروع**، **تحليل الأداء**، و**التنبيهات**.
- تحسين التباعد بين البطاقات، عرض حالات التقييم، التصميم Responsive، وتوافق RTL/LTR.
- نتائج بحث مرتبة في جدول مختصر يعرض اسم الفرع، التقييم، عدد المراجعات المعلن، درجة التطابق، حالة النتيجة والعنوان. الحقول التفصيلية ما زالت متاحة في قسم منفصل.
- القيم التي لم يرسلها مصدر البيانات لا تعرض كأنها صفر. لا يظهر عدد مراجعات مكتمل ما لم يتوفر من المصدر.

## ملفات التوزيع

**Windows Setup:** تثبيت عادي مع اختصار في قائمة Start وسطح المكتب (اختياري). البيانات والإعدادات تحفظ خارج ملفات البرنامج تحت:

`%LOCALAPPDATA%\ProTech\GoogleMapsReviewsTracker`

**Windows Portable:** فك ضغط ZIP كاملًا، ثم تشغيل `Start_Portable.cmd` أو `ReviewsTracker45.exe` مباشرة. لا يحتاج إلى التثبيت، ويحتفظ بالبيانات والإعدادات في:

`GoogleMapsReviewsTracker_v45_Portable\Data\`

احفظ مجلد `Data` مع البرنامج عند النقل أو التحديث. النسخة المحمولة **لا تستورد تلقائيًا** قاعدة بيانات النسخة المثبتة: يجب استخدام نسخة احتياطية من البرنامج أو مسار استعادة مناسب. لا تنقل قاعدة SQLite مفتوحة أثناء عملها. لا تشغل نسختين في الوقت نفسه على المنفذ `127.0.0.1:8597`.

## الاختبار والأمان

- اختبارات Regression والتخزين المحمول والفروع.
- اختبار الواجهة العربية بثلاث دقات شاشة، بما فيها عرض الأيقونة والبطاقات والانتقال بين الصفحات.
- اختبار التثبيت النظيف وفتح البرنامج من الحزمة نفسها، وفحص الحزمة من قواعد البيانات ومفاتيح API.
- اختبار تشغيل النسخة المحمولة بعد فك الضغط وحفظ بياناتها محليًا دون إنشاء أو تعديل بيانات النسخة المثبتة.
- ملفات `SHA256SUMS.txt` للتحقق من سلامة التنزيل.

## القيود المعروفة

الإصدار **Beta غير موقّع رقميًا**. المعلومات القديمة أو الناقصة تعرض على أنها محفوظة أو جزئية، ولا يوجد ضمان بكونها متزامنة لحظيًا مع Google. جلب مراجعات المواقع المملوكة بكاملها يتطلب حساب Google Business Profile مصرحًا له عبر OAuth. لا تَعِد Places API بتغطية كل مراجعات المنافسين. لا تضاف معلومات مراجعات أو تقييمات مختلقة.
