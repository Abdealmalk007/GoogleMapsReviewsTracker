# Google Maps Reviews Tracker v46.0.0 Beta 1

## عرض التعليقات والمراجعات المحفوظة

يعرض قسم **التعليقات** جميع المراجعات المحفوظة افتراضيًا، وليس فقط ما جُلب خلال آخر 30 يومًا. يظهر القسم مباشرة في القائمة الرئيسية.

### البحث والفلاتر

- البحث داخل نص التعليق أو الكاتب أو الموضوع أو الفرع
- حسب الفرع والتقييم 1–5 نجوم والمشاعر
- حالة الرد: تم الرد، بدون رد، غير معروف
- تعليقات لها نص أو تقييم دون نص
- فترة الاستيراد: الكل، 7/30/90/365 يومًا
- حالة المتابعة والأولوية والموضوع
- الترتيب بتاريخ الاستيراد الفعلي أو التقييم أو الكاتب أو الردود

تظل تعبيرات Google مثل «قبل شهرين» كما وردت ولا تتحول إلى تاريخ ميلادي مقدّر. لا تُعامل القيم المجهولة على أنها صفر.

### بطاقات أو جدول

تظهر كل مراجعة في بطاقة ذات مسافات واضحة: الفرع، المراجع، النجوم المعروفة، التعليق كاملًا، رد المالك المحفوظ، المشاعر، الموضوع، وتاريخ التعليق الأصلي وتاريخ الاستيراد. يمكن التحويل إلى جدول، تحديد حجم الصفحة، تصدير CSV للصفحة المفلترة، ومسح الفلاتر.

تتوفر إجراءات فردية وجماعية لمتابعة التعليقات، وتحديد الأولوية وإضافة ملاحظات محلية، دون النشر التلقائي لأي رد على Google.

### الأيقونة المعتمدة

الأيقونة الرسمية المصممة في v45 محفوظة كما هي في ملفات PNG وICO، وفي برنامج Windows وDashboard. تمت إضافة CSS v46 لتنسيق بطاقات المراجعات مع الهوية الزرقاء والبيضاء RTL/LTR.

### التوزيع

Windows Setup: تحتفظ بيانات النسخة المثبتة في مجلد بيانات المستخدم المحلي.

Windows Portable: يجب فك ضغط ZIP كاملًا، ثم تشغيل Start_Portable.cmd. تحفظ هذه النسخة بياناتها في مجلد Data بجوار الملف التنفيذي. احتفظ بمجلد Data عند التحديث.

### الاختبارات والحدود

توجد اختبارات SQL وRegression وبصمات المصدر وعرض متصفح Edge بثلاث دقات شاشة، مع اختبار تصدير CSV. الاختبار على نسخة QA من البيانات، دون تعديل المصدر الأصلي للبيانات.

الإصدار Beta غير موقّع رقميًا. مزامنة Google Business Profile الحية تتطلب OAuth مصرحًا به، ولا يمكن استخراج جميع مراجعات المنافسين من Places API.
