# Google Maps Reviews Tracker v44.0.0 Beta 1

## إصلاحات البحث والواجهة

- إصلاح أزرار قوائم البحث والفرز والفلاتر والتصدير في Streamlit لتظهر بخلفيات فاتحة ونصوص واضحة، وحالات Hover وFocus متناسقة.
- معالجة تداخل النص الإرشادي مع محتوى حقل البحث أثناء الكتابة بالعربية والإنجليزية، وضبط لون النص ومؤشر الكتابة.
- توحيد أنماط أزرار Primary وSecondary وDownload مع مظهر Dashboard المعتمد.
- تقصير النص الإرشادي في فلتر النتائج، حتى لا يزدحم الحقل على الشاشات المتوسطة.
- إعادة استخدام DataFrame المعالج للبحث المكتمل أثناء الفرز والفلترة، ما يقلل التكرار المكلف لتحليل النتائج.
- لا يتم تثبيت النتائج المؤقتة أثناء استمرار البحث الحي، منعًا لإظهار بيانات قديمة.

## التحقق

- 44/44 اختبار Regression ناجح.
- فحوص متصفح Playwright على 1600 و1366 و900 بكسل باستخدام بيانات بحث QA اصطناعية.
- فحص فعلي لأربعة أزرار قوائم: الخلفية بيضاء والنص داكن، ولا توجد أزرار سوداء.
- كتابة النص العربي «نانو كيتشن» في الفلتر؛ النص واضح ويختفي placeholder، مع الاحتفاظ بالقيمة بعد Enter.
- صفر استثناءات Streamlit أو تمرير أفقي في الثلاث دقات.

## حدود الإصدار

الإصدار Beta غير موقّع رقميًا. التحسينات تتعلق بعرض البيانات وواجهة البحث والأداء، ولا تثبت مزامنة حية مع Google Business Profile؛ تتطلب المزامنة تفويض OAuth مصرحًا به. لم يتم تعديل قاعدة البيانات الأصلية أو تضمين بيانات المستخدم داخل الحزمة.
